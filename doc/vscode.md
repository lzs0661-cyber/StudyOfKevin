## 导航功能

### Quick file navigation
     You can open any file by its name when you type ⌘P

### Open symbol by name
    jumping to a symbol across files with ⌘T

### Go to Symbol
    navigate symbols inside a file with ⇧⌘O

### Breadcrumbs
在文件的上方有导航栏，可以快速在文件和符号中切换

### Go to Definition
   - go to the definition of a symbol by pressing F12.
   - the implementation of a symbol by pressing ⌘F12
  
### Peek
    you execute a Go to References search (via ⇧F12), or a Peek Definition (via ⌥F12), 

### Rename symbol
    Press F2 and then type the new desired name and press Enter. All usages of the symbol will be renamed, across files.

### Errors & warnings
    You can click on the summary or press ⇧⌘M to display the PROBLEMS panel with a list of all current errors.
